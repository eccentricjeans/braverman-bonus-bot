# Бонусный Telegram-бот

Бот разделяет режимы клиента и администратора, хранит данные в SQLite и работает по принципу «условия начисления фиксируются в момент операции»:

- процент начисления и срок действия берутся из текущих настроек только при новом начислении;
- уже начисленные бонусы сохраняют исходную дату истечения и не меняются после корректировки настроек;
- списание идёт с ближайших к истечению бонусов.

## Запуск

1. Установите Python 3.11+.
2. Создайте окружение и установите зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN` и `ADMIN_IDS`.
4. Запустите `python bot.py`.

Клиент открывает бота, нажимает «Отправить номер» и разрешает передачу контакта. Администратор вводит `/start` и видит административное меню.

## Что умеет бот

- Клиент: регистрация по Telegram-контакту, общий баланс и разбивка бонусов по датам истечения, уведомления о начислении и списании.
- Администратор: поиск клиента по номеру телефона, выбор из списка совпадений, карточка клиента, начисление от суммы покупки, списание доступного остатка, настройка процента и срока действия.

> Для защиты доступа добавляйте в `ADMIN_IDS` только доверенные Telegram ID. Не используйте username: он может измениться.
